# Эмулятор оболочки

Графический прототип эмулятора командной строки UNIX-подобной ОС.
На этом этапе команды `ls` и `cd` — заглушки: они печатают своё имя и аргументы. Команда `exit` закрывает окно

## Функции и настройки

Имя VFS задано константой `VFS_NAME` в `src/main.py` и попадает в заголовок окна. Сейчас это `vfs`


| Модуль            | Что делает                                          |
| ----------------- | --------------------------------------------------- |
| `src/parser.py`   | Делит строку по пробелам на команду и аргументы     |
| `src/commands.py` | Выполняет `ls`, `cd`, `exit` или сообщает об ошибке |
| `src/main.py`     | Окно: область вывода и поле ввода                   |


Ошибки:

- пустая строка — `ошибка: пустая команда`;
- любая другая команда — `ошибка: неизвестная команда: <имя>`.

Ввод подтверждается клавишей Enter. В области вывода видна и строка
пользователя (с префиксом `>`), и ответ эмулятора

## Сборка и тесты

Отдельная сборка не нужна: достаточно Python 3 со стандартной
библиотекой `tkinter`

Запуск:

```
run.bat
```

или

```
sh run.sh
```

В папке `tests` лежат заглушки
