# Эмулятор оболочки

Графический прототип эмулятора командной строки UNIX-подобной ОС.
Команды `ls` и `cd` пока заглушки. Они печатают своё имя и аргументы.
Команда `exit` закрывает окно.

## Функции и настройки

Имя VFS задано константой `VFS_NAME` в `src/main.py` и выводится
в заголовке окна. Текущее значение этой константы `VFS`.

Параметр `--vfs` задаёт путь к физическому расположению VFS.
Параметр `--script` задаёт путь к стартовому скрипту.
Оба значения печатаются в окно при старте. Если параметр не передан,
вместо пути выводится текст `не задан`.

Стартовый скрипт выполняется до ввода с клавиатуры.
Строка, которая начинается с `#`, пропускается как комментарий.
В окне показываются команда с префиксом `>` и ответ эмулятора.
Ошибка чтения скрипта и ошибка команды печатаются в это же окно.
После ошибочной строки скрипт продолжает выполнение.

| Модуль | Назначение |
| --- | --- |
| `src/parser.py` | Делит строку по пробелам на команду и аргументы |
| `src/commands.py` | Выполняет `ls`, `cd`, `exit` или сообщает об ошибке |
| `src/config.py` | Читает `--vfs` и `--script`, готовит отладочный вывод |
| `src/script.py` | Читает стартовый скрипт и выполняет его команды |
| `src/main.py` | Окно с областью вывода и полем ввода |

Пустая строка считается ошибкой.
Неизвестная команда тоже считается ошибкой. В сообщении будет её имя.
Если стартовый скрипт не удалось прочитать, в окне будет сообщение
с путём к файлу.

Ввод подтверждается клавишей Enter.

## Сборка и тесты

Отдельная сборка не нужна. Достаточно Python 3 со стандартной
библиотекой `tkinter`.

Запуск в Windows.

```
run.bat
```

Запуск через `sh`.

```
sh run.sh
```

В папке `tests` лежат заглушки. Отдельный запуск тестов на этом этапе
не нужен.

Проверка параметров выполняется из папки `emulator`.

```
scripts\no_args.bat
scripts\vfs_only.bat
scripts\script_only.bat
scripts\both.bat
scripts\bad_script.bat
```

`bad_script.bat` передаёт путь к несуществующему скрипту. В окне
появится ошибка чтения.

## Примеры

Запуск без параметров печатает оба пути как не заданные. Дальше можно
вводить команды.

```
Команды: ls, cd, exit
vfs_path=не задан
script_path=не задан
> ls
ls
> ls docs a.txt
ls docs a.txt
> cd /home
cd /home
>
ошибка: пустая команда
> rm file
ошибка: неизвестная команда: rm
> exit
```

Файл `scripts/startup.txt` содержит комментарий и команды `ls`, `cd`,
`rm`. Его подключает `scripts\both.bat`.
